# 🧠 Virtual Assistant (Web-Based)

A browser-based **Virtual Assistant** built using **HTML, CSS, and JavaScript** that supports **voice recognition**, **text-to-speech**, and **command-based interaction** using modern Web APIs.

---

## 🚀 Features

* 🎙️ Voice input using **Web Speech API**
* 🔊 Spoken responses with **Text-to-Speech (TTS)**
* 🕒 Time-based greetings (Morning / Afternoon / Evening)
* 🔁 Continuous listening mode
* ❌ Exit command with polite voice response
* ♿ Accessible UI with ARIA support
* 🌐 Runs completely in the browser (no backend)

---

## 👀 Visible UI Elements

### 🔘 Buttons

* **Start Listening** – Activates voice recognition
* **Ask Again** – Restarts listening after a command
* **Exit** – Stops the assistant and speaks a thank-you message

### 📝 Display Areas

* **Command Display Panel** – Shows the recognized speech text
* **Status Indicator** – Indicates whether the assistant is listening or idle

### 🎨 UI Design

* Clean and minimal layout
* Responsive design for desktop browsers
* Visual feedback for active commands

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **JavaScript (ES6)** – Logic and interaction
* **Web Speech API** – Speech Recognition & TTS

---

## 🧩 How It Works

1. User clicks **Start Listening**
2. Assistant listens to voice input
3. Speech is converted to text
4. Text is displayed on the screen
5. Command is processed
6. Assistant responds with voice output
